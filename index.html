About Me

I'm a Java Full Stack Developer with more than five years of experience building and supporting enterprise applications in retail banking, automotive manufacturing and enterprise IT services. Most of my work is on the back end: Spring Boot microservices, REST APIs, Kafka event streams and AWS services. I also build React and Angular screens for the teams who use those systems.

A large part of my career has been modernization. I've moved legacy Java/J2EE and batch applications onto Spring Boot microservices running on OpenShift, and migrated high-volume customer, transaction and supply-chain data to AWS with DMS, Glue and Spring Batch. Those migrations included validation, retry and reconciliation, so the data arrives complete and correct.

I care about software that is secure and well tested: least-privilege IAM, protected PII, automated CI/CD pipelines, JUnit/Mockito test suites and clear code reviews. I enjoy hard integration problems where many systems have to agree on the same data.

Solution
A Spring Batch chunk job that reads, validates, transforms and writes records, with skip and retry policies, restart from the last commit and a reconciliation report.

Vendor Feed Processor

Serverless AWS data pipeline
Problem
Partner payment files arrive at random times and in bursts, and every record must be processed exactly once.
Solution
An S3 upload triggers a Lambda that splits the file into SQS messages. A second Lambda validates each record and writes it idempotently to DynamoDB, with a DLQ for failures.
